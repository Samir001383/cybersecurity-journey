# Day 5: Harvard CS50 (Security, Malware & Software)

## 1. Networking & Infrastructure
* **VPN:** Creates a secure, encrypted connection over a less secure network like the internet.
* **SSH (Secure Shell):** A cryptographic network protocol used to securely operate network services over an unsecured network.
* **IP Address & Port Numbers:** IP addresses identify devices on a network, while port numbers identify specific processes or services running on those devices.
* **Firewall:** A network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. 
* **Deep Packet Inspection:** An advanced method of examining and managing network traffic, looking at the actual data payload of the packet, not just the header.
* **Proxy Server:** An intermediary server that separates end-user clients from the destinations they browse.

## 2. Security Teams & Testing
* **Ethical Hacking & Penetration Testing (Pen Testing):** Authorized practice of bypassing system security to identify potential data breaches and threats.
* **Port Scanning:** Probing a server or host for open ports to identify vulnerabilities.
* **Red Team:** Offensive security professionals who act as adversaries to test a system's defenses.
* **Blue Team:** Defensive security professionals who maintain internal network defenses against cyber attacks.

## 3. Malware & Network Attacks
* **Malware:** Malicious software designed to disrupt, damage, or gain unauthorized access.
  * **Virus:** Malware that attaches to clean files and infects other clean files.
  * **Worm:** Malware that replicates itself to spread to other computers without needing to attach to a host program.
* **Botnet:** A network of private computers infected with malicious software and controlled as a group without the owners' knowledge.
* **DoS (Denial of Service):** An attack meant to shut down a machine or network, making it inaccessible to its intended users.
* **DDoS (Distributed Denial of Service):** A DoS attack that uses multiple compromised systems as sources of attack traffic.
* **Zero-Day Attacks:** An attack that exploits a previously unknown vulnerability in a computer application, meaning developers have had "zero days" to fix it.
* **Phishing:** A fraudulent attempt to obtain sensitive information by disguising oneself as a trustworthy entity in electronic communication.

## 4. Securing Software & Web Apps
* **Securing Software:** The overarching practice of protecting applications from external threats.
* **Code Injection:** Exploitation of a computer bug that is caused by processing invalid data.
* **Cross-Site Scripting (XSS):** A type of injection vulnerability where an attacker injects malicious scripts into otherwise benign and trusted websites.
  * **Reflected Attack:** The injected script is reflected off the web server, such as in an error message or search result.
  * **Stored Attack:** The injected script is permanently stored on the target servers, such as in a database or message forum.
* **Character Escapes:** A defensive programming technique used to prevent injection attacks by telling the system to treat special characters as regular text, not as executable code.

## 5. Basic Defenses
* **Antivirus:** Software designed to detect and destroy computer viruses.
* **Automatic Updates:** Ensuring systems and software are patched immediately to protect against known vulnerabilities.
